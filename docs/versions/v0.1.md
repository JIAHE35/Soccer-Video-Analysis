# V0.1 - Baseline Football Object Detection

**Status:** Complete

**Git reference:** `3b6567b`

**Milestone:** Run a soccer video through pretrained YOLO and create an
annotated output video.

## Goal

V0.1 intentionally focused on the smallest end-to-end pipeline:

```text
30 FPS soccer video
  -> pretrained YOLO11n
  -> person and sports-ball detections
  -> colored bounding boxes
  -> annotated MP4
```

The purpose was to prove that video frames could be read, processed, annotated,
and written successfully before adding tracking or soccer-specific logic.

## Implementation

- Used the pretrained `yolo11n.pt` model without custom training.
- Mapped the COCO `person` class to the project label `player`.
- Mapped `sports ball` to `ball`.
- Drew green player boxes and blue ball boxes.
- Reserved a red referee color, although the pretrained model could not
  distinguish referees from other people.
- Converted the variable-frame-rate source to a constant 30 FPS H.264 video
  before inference.

## Configuration

| Setting | Value |
| --- | --- |
| Input | `data/soccervideo_cfr.mp4` |
| Historical default output | `outputs/detected_cfr.mp4` |
| Model | `yolo11n.pt` |
| Image size | `960` |
| Shared confidence threshold | `0.25` |
| Tracking | None |
| Field filtering | None |

## What worked

- The complete input-to-output video pipeline ran successfully.
- Most clearly visible field players received bounding boxes.
- The output preserved the 30 FPS playback speed of the normalized input.
- The project gained a reproducible CLI, requirements file, Git ignore rules,
  and initial tests.

## Limitations discovered

- Spectators and sideline staff were detected as players because every `person`
  detection was accepted.
- Players did not have persistent identities between frames.
- Players and referees could not be separated.
- A single confidence threshold was a poor fit for both large people and the
  much smaller soccer ball.
- Ball detections were intermittent, and small white pitch markings could look
  similar to a ball.

These observations motivated V0.2's field-aware filtering and separate
confidence thresholds.

## Reproduce this version

The exact historical source can be inspected without changing the working tree:

```bash
git show 3b6567b:src/detect.py
git show 3b6567b:README.md
```

To run the historical detector from a temporary file:

```bash
git show 3b6567b:src/detect.py > /tmp/soccer_detect_v01.py
python /tmp/soccer_detect_v01.py \
  --source data/soccervideo_cfr.mp4 \
  --output outputs/v01_player_detection.mp4 \
  --conf 0.25
```

The retained `outputs/comparison_v01_v02.mp4` artifact shows V0.1 and V0.2 at
the same video timestamps.
