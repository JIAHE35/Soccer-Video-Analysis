# V0.2 - Field-Aware Detection

**Status:** Complete

**Git references:** `155f1d3` introduced V0.2; `009ac8a` contains its final
confidence defaults.

**Milestone:** Reduce spectator false positives while keeping field players and
balls visible.

## Goal

V0.1 treated every detected person as a field player. V0.2 added inexpensive
soccer-specific context without training a new model:

```text
YOLO detection
  -> class-specific confidence threshold
  -> grass-field support check
  -> accepted field detection
  -> annotated MP4
```

## Changes from V0.1

- Added separate confidence thresholds for players and balls.
- Built a rough grass mask in HSV color space for every frame.
- Validated people using the bottom-center point of their bounding boxes.
- Validated balls using the center point of their bounding boxes.
- Added a lower-box fallback for close-up players cropped by the frame edge.
- Added tests for label mapping, frame rate handling, field anchors, grass
  support, and rejected off-field detections.

## Final configuration

| Setting | Value |
| --- | --- |
| Input | `data/soccervideo_cfr.mp4` |
| Current archived output | `outputs/v02_player_detection.mp4` |
| Model | `yolo11n.pt` |
| Image size | `960` |
| Player confidence | `0.5` |
| Ball confidence | `0.3` |
| Minimum green ratio | `0.25` |
| Tracking | None |

The first V0.2 commit used `player_conf=0.45` and `ball_conf=0.15`. Visual
inspection led to the final `0.5` and `0.3` defaults in commit `009ac8a`.

## What improved

- Many spectator detections in the stands were removed.
- People near advertising boards were less likely to be labeled as players.
- Player and ball thresholds could be tuned independently.
- V0.2 produced a clearer visual result without a custom dataset or model.

## Limitations discovered

- The grass mask was heuristic and could reject valid detections near the image
  edge or accept people standing close to the pitch.
- Every accepted person was still labeled `player`; referees were not separated.
- There was no persistent ID, so player movement could not be measured.
- Raising the ball threshold reduced false positives but also increased missed
  balls.

These limitations motivated V0.3's person tracking and independent low-threshold
ball pass.

## Reproduce this version

```bash
git show 009ac8a:src/detect.py > /tmp/soccer_detect_v02.py
python /tmp/soccer_detect_v02.py \
  --source data/soccervideo_cfr.mp4 \
  --output outputs/v02_player_detection.mp4 \
  --player-conf 0.5 \
  --ball-conf 0.3 \
  --min-field-green-ratio 0.25
```

The retained `outputs/comparison_v01_v02.mp4` artifact shows the reduction in
off-field person detections at matching timestamps.
